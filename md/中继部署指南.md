# WebSocket 中继部署指南

## 推荐方案: Fly.io（免费, 无休眠, 香港节点延迟低）

### 步骤

1. 注册 Fly.io 账号: https://fly.io
2. 安装 flyctl (Windows PowerShell 管理员模式):

```powershell
iwr https://fly.io/install.ps1 -useb | iex
```

3. 登录:

```powershell
flyctl auth login
```

4. 部署 (在项目根目录执行):

```powershell
cd "E:\Codex Projects\企业微信群发系统"
flyctl launch --name wecom-broadcast-relay --region hkg
```

首次部署会提示创建 app, 选择已存在的 `fly.toml` 配置即可。

5. 获取中继地址:

```powershell
flyctl status
```

地址格式: `wss://wecom-broadcast-relay.fly.dev`

6. 更新本项目的 config.yaml:

```yaml
relay:
  url: "wss://wecom-broadcast-relay.fly.dev"
```

### Fly.io 免费额度
- 3 个共享 VM (256MB)
- 30GB 磁盘
- 无限流量 (合理使用)
- 无休眠 (不像 Render)

---

## 备用方案: Render.com（GitHub 自动部署, 但会休眠）

1. Fork 本项目到 GitHub
2. 登录 Render: https://render.com
3. 新建 Web Service → 连接 GitHub 仓库
4. Render 自动读取 `render.yaml`
5. 获取地址: `wss://wecom-broadcast-relay.onrender.com`

> ⚠️ 免费层 15 分钟无活动会休眠, WebSocket 连接会断开。建议用 Fly.io
