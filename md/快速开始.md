# 企业微信群发系统 — 快速开始指南

## 一、环境准备（每台机器都要做）

### 1. 安装 Python 依赖

```powershell
pip install -r requirements.txt
pip install uiautomation  # UIA 扫描（可选，有 OCR 降级）
```

### 2. 运行诊断

```powershell
python diagnose.py
```

确保 11 项全部通过。

---

## 二、配置

### 1. 员工识别（`data/staff_patterns.yaml`）

如果同事在企微群里有统一前缀（如"某某科技-张三"），设置：

```yaml
staff_prefix: "某某科技-"
```

系统会**优先使用 UI 扫描**群成员面板的"客户"标签，准确率最高。
前缀只是降级备用。

### 2. 群列表（`data/groups.yaml`）

把实际客户群名填入，或通过 Web 面板导入：
- 打开 `http://localhost:8080`
- 群管理 → 批量导入 → 粘贴群名（一行一个）

### 3. 消息模板（`data/templates/default.j2`）

编辑默认发送模板。

---

## 三、启动

### 主控端（群主机器）

```powershell
.\start_master.ps1
```

自动完成：
1. 启动 WebSocket 中继（端口 3000）
2. 启动 Cloudflare 隧道（生成公网地址）
3. 更新配置
4. 启动主控面板（`http://localhost:8080`）

最后会输出执行端连接命令，发送给同事即可。

### 执行端（同事机器）

```powershell
.\start_worker.ps1 -RelayUrl "wss://xxx.trycloudflare.com"
```

---

## 四、打包发布

```cmd
build.bat
```

产物：
- `dist\wecom-broadcast-master\` — 主控端
- `dist\wecom-broadcast-worker\` — 执行端

---

## 五、端口规划

| 服务 | 端口 |
|---|---|
| relay 中继 | 3000 |
| master 主控面板 | 8080 |
| cloudflared 隧道 | 自动分配到公网 |

---

## 六、常用命令

```powershell
# 环境诊断
python diagnose.py

# 直接启动主控（不用脚本）
python main.py --mode master

# 直接启动执行端
python main.py --mode worker --relay wss://xxx.trycloudflare.com

# 查看中继日志
Get-Content logs\relay.log -Tail 50
```
